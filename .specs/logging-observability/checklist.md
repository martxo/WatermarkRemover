# 验收清单：操作级可观测日志

## 格式与解析

- [x] 日志行格式为 `时间 [级别] [类别] [op=…] [t=…] 消息`，级别固定 5 字符
- [x] `LogFilter` 能解析新格式的 Category / OperationId / ThreadId
- [x] `LogFilter` 仍能解析旧格式 `时间 [INFO] 消息`
- [x] 异常续行堆栈仍合并到上一条记录
- [x] `LogLine.Format` 与 `LogFilter` 往返一致

## 级别与关联

- [x] 默认最低级别为 DEBUG，`WMR_LOG_LEVEL` 可覆盖
- [x] 嵌套操作复用父操作 ID，根操作分配六位序号
- [x] 每条关键记录带线程号
- [x] 错误立即 flush；普通行按 16 行 / 1 秒 flush
- [x] 启动记录 OS/架构/CPU/用户/区域/.NET 与内存
- [x] 退出时 `Shutdown` 强制 flush
- [x] 未处理异常记录后 `Flush`

## 扫描链路

- [x] 扫描会话有操作开始/完成/失败，含耗时与页数
- [x] 每个扫描源探测有耗时与可用性
- [x] 逐页记录读取耗时、像素尺寸、编码耗时、payload 大小
- [x] 页面排序、生成 PDF、写入文件各有耗时
- [x] 扫描忙、取消、闸门释放均有日志
- [x] 页面到达（页号、尺寸、缩略图 KB）有 DEBUG 记录

## 命名链路

- [x] 自动命名 / 首屏命名 / 命名落盘各有操作与耗时
- [x] 方向校正、固定区域定位、整页 OCR、规则命名各有步骤耗时
- [x] 后台命名记录等待预览稳定、复用首屏结果、探测、落盘
- [x] 手动改名记录旧名→新名、尝试次数、耗时；失败有 ERROR

## 预览与图像操作

- [x] 打开预览记录页数、首屏渲染、总耗时
- [x] 扫描后处理 / 空白清理 / 自动摆正各有操作与逐页耗时
- [x] 缩略图填充记录页数、成功数、总耗时
- [x] 渲染记录页号、DPI、耗时；失败为 WARN
- [x] 缓存命中/未命中/闸门等待/淘汰均有记录
- [x] 旋转 / 删除 / 插入扫描页各有操作、页号、写盘耗时
- [x] 空白判定、缩略图、文件找回的静默失败不再静默

## 任务队列

- [x] 单任务有 JOB 操作：CanHandle、执行耗时、状态、输出路径
- [x] 排队等待耗时有 DEBUG 记录
- [x] 批次开始/结束有文件数、并发数、总耗时（不共用操作 ID）
