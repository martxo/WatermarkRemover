# WatermarkRemover

PDF 右下角角标水印去除工具（Windows 桌面版）。

## 下载

前往 [Releases](https://github.com/martxo/WatermarkRemover/releases) 页面下载最新的 `WatermarkRemover.exe`，单文件免安装，双击即用。

## 功能

- 把 PDF 拖进窗口即自动去除右下角角标水印（扫描件导出类水印）
- 支持一次拖入多个文件，输出到同目录或指定目录
- 自定义输出文件名后缀

## 更新

软件启动时自动检查新版本，也可以在「设置 → 软件更新」中手动检查，更新无需重新安装。
